# Sistema de Gestión Escolar - ERP

ERP completo para institución educativa con niveles Inicial, Primaria y Secundaria.

## Estructura
- `docs/` - Documentación del proyecto
  - `database/` - Esquema SQL
  - `flows/` - Diagramas de flujo de procesos
- `api/` - Backend NestJS (próximamente)
- `web/` - Web institucional Next.js (próximamente)
- `padres/` - App para padres (próximamente)
- `intranet/` - Panel administrativo (próximamente)

## Stack
- NestJS, Prisma, PostgreSQL, Next.js, React
