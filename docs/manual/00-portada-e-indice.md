# Manual integral de Gestión Escolar ERP

## Propósito

Este manual explica el funcionamiento general de Gestión Escolar ERP para propietarios del producto, administradores, usuarios, desarrolladores, soporte y futuras personas que participen en el proyecto.

Está diseñado para poder leerse en pantalla o imprimirse.
