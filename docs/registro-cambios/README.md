# Registro funcional de cambios

Esta carpeta registra los cambios que modifican el comportamiento del producto.

No reemplaza el historial de Git.

El historial de Git explica qué líneas cambiaron.

Este registro explica:

- Por qué cambiaron.
- Qué regla se modificó.
- Qué comportamiento anterior existía.
- Qué comportamiento nuevo existe.
- Qué casos fueron considerados.
- Qué pruebas se realizaron.
- Qué riesgos permanecen.

Cada cambio debe utilizar la plantilla:

`docs/plantillas/plantilla-cambio.md`

## Convención de nombre

`AAAA-MM-DD-titulo-del-cambio.md`

Ejemplo:

`2026-07-21-promocion-entre-instituciones.md`
