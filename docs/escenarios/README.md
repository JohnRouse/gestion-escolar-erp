# Escenarios funcionales

Esta carpeta documenta situaciones que involucran uno o varios módulos.

Cada escenario debe incluir:

- Situación inicial.
- Actores.
- Permisos.
- Datos necesarios.
- Flujo.
- Validaciones.
- Resultado esperado.
- Mensajes.
- Trazabilidad.
- Reversión.
- Estado de implementación.

## Escenarios iniciales

- Usuario con un colegio.
- Usuario con varios colegios.
- Todos los colegios.
- Cambio de colegio activo.
- Continuidad en la misma institución.
- Continuidad en otra institución del grupo.
- Traslado externo.
- Recuperación pedagógica.
- Permanencia.
- Egreso.
- Falta de cupos.
- Falta de año lectivo siguiente.
- Progresión académica ausente.
- Ejecución duplicada.
- Ejecución parcial.
- Reversión.
- Pago observado.
- Pago rechazado.
- Pago anulado.
- Acceso no autorizado.
- Recurso de otro tenant.
- Caída temporal del servicio.
